Tower of Hanoi

A sleek, interactive digital version of the legendary mathematical puzzle. This project focuses on a minimalist aesthetic and smooth user experience, bringing the classic logic challenge to your browser.
🚀 The Vision

This project is a vibe-coded creation. It was developed by translating high-level creative intent and natural language into a functional game. As the creator, I steered the design, logic, and polish of the experience, using AI-augmented development to rapidly iterate and bring the "vibe" of the game to life.
🎮 The Challenge

The game consists of three rods and a set of disks of different sizes. The objective is to move the entire stack from the starting rod to the target rod in the fewest moves possible.
📜 The Rules

To successfully solve the puzzle, you must follow these three fundamental constraints:

    Single Movement: Only one disk can be moved at a time.

    Top-Down Only: You can only move the uppermost disk from one stack and place it on top of another stack or an empty rod.

    Size Constraint: No larger disk may be placed on top of a smaller disk. A disk can only be placed on an empty rod or on a disk larger than itself.

🛠️ How to Play

    Select the top disk from any rod.

    Move it to a valid rod according to the rules above.

    Win the game by recreating the original stack on the final rod.

For a game with n disks, the mathematical minimum number of moves required is 2n−1. Can you reach the perfect score?
